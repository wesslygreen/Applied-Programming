# Flashcard App (Kotlin)

For this module I created a Flashcard app where the users can create decks, add cards that includes questions and answers, quiz themselves, and track the amount they got correct and incorrect.The program saves decks and allows the user to review them later if necessary.

## Instructions for Build and Use

[Software Demo]https://youtu.be/9ReDO7K6olg

Steps to build and/or run the software:

1. I needed to install Kotlin and Java to make this run in VS code
2. After adding the code with help from multiple resources, you open the terminal and run kotlinc main.kt -include-runtime -d main.jar
3. Compile the program

Instructions for using the software:

1. When the program starts you need to Enter a deck name
2. Choose one of the 5 options 
3. Follow the prompts and enter the answers and also selct the amount of right and wrong answers.
